# Madhurima Ghosh — Developer Portfolio

A responsive single-page developer portfolio built with HTML, CSS and vanilla JavaScript. It features the StudentFlow full-stack project and selected screenshots from its live admin and student workflows.

## Run locally

1. Extract the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step or package installation is required.

## Project showcase

The StudentFlow section links to the live application and GitHub repository. Eight original 1920×1080 screenshots are stored in `assets/screenshots/` and displayed in the product gallery. Select a gallery image to open it at full size.

## Portfolio content

- Education and academic results are based on the resume supplied by Madhurima.
- StudentFlow is the featured project; the BioBeat AI entry from the resume has intentionally been excluded because it is not a project to showcase.
- The contact section uses the supplied Gmail address. A personal phone number is intentionally not published.
- Five certificates/courses and the listed interests are included based on the supplied resume and conversation details.

## Before publishing

- Review all content and confirm the public GitHub, live application and email links.
- Add a LinkedIn URL only if Madhurima chooses to share one.
- Do not add a public phone number unless she explicitly requests it.

## Deploy

This is a static website. It can be deployed using any static-site host. For Render, create a **Static Site** connected to the portfolio GitHub repository; use the repository root as the publish directory. No build command is needed.
